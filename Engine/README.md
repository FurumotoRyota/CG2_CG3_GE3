# Divergence Engine

DirectX12 の自作エンジンです。ゲームごとのリポジトリから、サブモジュールとして `Engine/` に取り込んで使います。

- 変更点は [CHANGELOG.md](CHANGELOG.md) に書いてあります
- 便利な部品の一覧と使い方は、ゲーム側の README にあります。各ファイルの先頭のコメントにも書いてあります

## このリポジトリだけでは、ビルドできません

`EngineLib.vcxproj` は、ゲーム側のフォルダにある `externals/`（DirectXTex・assimp・ImGui）と `Common.props` を使います。
ゲームのリポジトリの `Engine/` として置いたときに、ビルドできます。

```
ゲームのリポジトリ/
  Common.props
  externals/
  Engine/        ← このリポジトリ（サブモジュール）
  Game/
```

## エンジンを変更したら

1. 変更して、ビルドが通ることを確認する
2. `CHANGELOG.md` に、何が変わったかを1〜数行で足す
3. コミットして push する（コミットメッセージは「何をしたか」を短く）
4. ゲーム側のリポジトリには、毎日自動で「Engine を新しい版にする」プルリクエストが作られる

## 素材のルール

エンジンに入れる画像・モデル・音は、必ず自作のものにします（授業のレギュレーションを守る）。
